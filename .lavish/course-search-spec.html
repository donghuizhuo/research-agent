One-sentence user story

As a UW Seattle course researcher, I can search by course code, department, keyword, or natural language and receive grounded course information with citations and clear uncertainty handling.

Retrieval rule

Use structured UW course retrieval first. Open-ended web search is only a labeled fallback, not the default source of authority.

State rule

Workflow state must explicitly persist active query, filters, selected courses, source IDs, citations, freshness, uncertainty, and task status.

Acceptance scenarios

  1. Exact course lookup returns title, department, number, credits, description, and citations when available.
  2. Department or keyword search returns a concise ranked list of relevant courses.
  3. Natural-language questions are interpreted and answered from structured course data when possible.
  4. Prerequisites are returned only when supported by retrieved sources.
  5. Quarter availability is answered only when quarter-specific data is available.
  6. If availability data is missing, the system says it cannot confirm availability.
  7. If structured retrieval lacks the answer, generic web snippets are not treated as authoritative.
  8. Source conflicts are surfaced with source identities.
  9. Sensitive student data is not required, stored, or used for MVP course search.
