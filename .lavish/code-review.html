The question this review answers

Is the implementation correct against the spec, and are the review findings resolved?

Yes. The agent stays source-grounded (LLM may only restate cited facts), retrieval is deterministic over approved snapshot data, and the grounding invariant is enforced by a deterministic verifier node. The flagged issues — dead code, a fragile FastAPI signature, a checkpointer connection leak, private cross-module usage, a misleading test name, an over-narrow classifier, and noisy FTS tokenization — are all fixed.

7 fixed 2 design notes

How the system fits together

Two lanes share one SQLite + FTS5 store. The runtime lane is the LangGraph agent; the ingestion lane is a manual Typer command that snapshots approved sources into the same store.

Deliberately left out of this pass

  • Real ingestion — courseagent ingest has not been run against live UW URLs; tests use fixture HTML. Requires network.
  • Live LLM path — the DeepSeek-backed classification/synthesis route is implemented but unverified without DEEPSEEK_API_KEY; the deterministic fallback is what the tests exercise.
  • FTS ranking tuning — BM25 thresholds are data-dependent and left for the first real-data pass; only stopword filtering is applied now.
  • Commit / push — all changes are currently uncommitted in the working tree.
